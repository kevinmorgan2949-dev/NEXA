# NEXA

A warm, responsive social space for sharing moments and finding your people. NEXA is a frontend demo built with React and Vite.

## Get started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Features

- Responsive desktop and mobile layouts
- Social feed with like, save, share, and comment interactions
- Story row and people suggestions with follow controls
- Search posts by profile, caption, or location
- Create a post with a caption and optional image upload

Posts and interactions are held in local component state for this demo. Photos load from Unsplash.
